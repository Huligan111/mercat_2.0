# Mercat - Asistente de compras

MVP de una aplicación web para la gestión y cálculo de compras mediante código de barras.

## Tecnologías
* Java & Spring Boot
* Spring Data JPA & Hibernate
* PostgreSQL (Supabase)
* Thymeleaf & REST API
* Maven
* Jenkins, Docker & Kubernetes
